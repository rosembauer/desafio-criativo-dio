Quero que a IA gere um cronograma semanal de estudos para estudantes de Engenharia de Software, 
com o objetivo de otimizar a assimilação de lógica de programação e rotinas de código em Python.

Passo 2: Adicione contexto e restrições

Considere o seguinte contexto: rotina de estudos EAD (educação a distância), dividida entre teoria, 
prática no VS Code e desenvolvimento de projetos pessoais.

Evite explicações teóricas longas, termos puramente 
acadêmicos sem aplicação prática e blocos extensos de código sem comentários.
